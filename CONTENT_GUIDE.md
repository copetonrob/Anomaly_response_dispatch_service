# Руководство автора контента

Все данные находятся в `src/content.js`. После изменений увеличивайте `version`, только если старое сохранение стало несовместимо.

## Обычная карта

```js
{
  id: "unique_card_id",
  kind: "incident",
  speaker: "Кто сообщает",
  title: "Короткий заголовок",
  text: "Одна ситуация, понятная без дополнительного лора.",
  image: "assets/cards/unique-card.webp",
  imagePosition: "center 45%",
  palette: ["#536875", "#11191d"],
  tags: ["budget", "public"],
  weight: 5,
  cooldown: 5,
  maxPlays: 3,
  conditions: [
    { type: "turn", op: "gte", value: 4 },
    { type: "flag", key: "war_active", equals: false }
  ],
  choices: {
    left: {
      label: "Первое решение",
      effects: [
        { type: "resource", key: "budget", amount: -0.08 },
        { type: "resource", key: "secrecy", amount: 0.06 }
      ]
    },
    right: {
      label: "Второе решение",
      effects: [
        { type: "resource", key: "personnel", amount: -0.06 },
        { type: "resource", key: "anomaly", amount: -0.07 }
      ]
    }
  },
  results: {
    left: {
      title: "Что произошло после первого решения",
      text: "Короткое раскрытие цены решения и его последствий.",
      reactions: {
        left: { label: "Мы не должны были этого делать" },
        right: { label: "Нам пришлось это сделать" }
      }
    },
    right: {
      title: "Что произошло после второго решения",
      text: "Другой исход для другой ветки.",
      reactions: {
        left: { label: "Запишите имена погибших" },
        right: { label: "Закрыть дело" }
      }
    }
  }
}
```

`image` и `imagePosition` необязательны. Без них карта использует абстрактный фон из своей `palette`. `imagePosition` принимает обычное CSS-позиционирование (`center`, `center 35%`, `left center`) и помогает удержать важный объект в кадре.

Ресурсы нормализованы в диапазоне `0..1`. Поэтому `amount: -0.08` отнимает 8% полной шкалы, а `amount: 0.06` добавляет 6%.

Отдельное поле подсказки не нужно. Во время свайпа движок сам находит ресурсные `effects`, берёт абсолютную величину эффекта и показывает над соответствующей иконкой нейтральный кружок. Чем больше `Math.abs(amount)`, тем крупнее кружок; направление изменения игроку не раскрывается.

## Последствия и реакции

После решения игра не переходит сразу к следующей ситуации. Она показывает `results.left` или `results.right` той же карты:

- `title` — короткий заголовок сводки;
- `text` — что произошло и почему изменились ресурсы;
- `reactions.left/right.label` — две эмоциональные реакции игрока.

Оба свайпа реакции по умолчанию ведут дальше. Движок сохраняет `last_reaction` и увеличивает счётчики `reaction_left` / `reaction_right`, поэтому позднее можно выдавать карты по характеру диспетчера.

Если реакции должны иметь сюжетное последствие, им можно добавить обычные эффекты:

```js
reactions: {
  left: {
    label: "Я этого не забуду",
    effects: [{ type: "flag", key: "remembers_victims", value: true }]
  },
  right: { label: "Подписать акт" }
}
```

Поражение и концовка проверяются после основного решения, но показываются лишь после прочтения результата и свайпа реакции. Игрок всегда успевает увидеть, какое решение привело к катастрофе.

## Вес, кулдаун и лимит

- `weight: 0` — карта не попадает в обычный пул; её можно получить только через очередь.
- `weight: 3..8` — типичный диапазон обычных карт.
- `cooldown: 5` — не показывать карту пять следующих ходов.
- `maxPlays: 1` — одноразовая карта.

Не делайте «важную» карту просто очень тяжёлой. Для обязательного события используйте `enqueue`; для вероятного — высокий вес и точные условия.

## Уровни мощности

Для ровного темпа полезно смешивать карты разной интенсивности:

- **Бытовая странность:** отдельные эффекты `0.02..0.05`, доступна с первого хода, вес `6..8`.
- **Тревожный инцидент:** эффекты `0.04..0.09`, обычно после 3–5-го хода, вес `5..7`.
- **Опасное событие:** эффекты `0.07..0.13`, после 7–10-го хода, вес `4..6`.
- **Кризис:** эффекты до `0.18`, после 12–14-го хода, низкий вес `3..4` и большой кулдаун.

Сумма модулей эффектов показывает общую «массу» выбора, но не должна заменять авторскую оценку. Потеря бюджета и рост аномальности одновременно обычно опаснее такого же суммарного изменения двух восстанавливаемых ресурсов.

## Ветвящийся сюжет

```js
effects: [
  { type: "flag", key: "archive_open", value: true },
  { type: "enqueue", cards: ["archive_part_2", "archive_part_3"] }
]
```

По умолчанию карты добавляются в начало очереди и будут идти подряд. `position: "back"` ставит их после уже запланированной последовательности.

Ветка создаётся разными очередями у левого и правого выбора:

```js
left: {
  label: "Сжечь папку",
  effects: [{ type: "enqueue", cards: ["archive_burned"] }]
},
right: {
  label: "Прочитать папку",
  effects: [{ type: "enqueue", cards: ["archive_read"] }]
}
```

## Карта активной фазы мира

```js
conditions: [
  { type: "flag", key: "war_active", equals: true }
],
tags: ["war"]
```

Добавьте в `tagRules` правило для `war`, чтобы во время события такие карты не просто стали возможны, а преобладали в выдаче.

## Авторские рекомендации

- Ситуация должна читаться за 4–8 секунд.
- Два решения должны отражать разные приоритеты, а не «хорошо / плохо».
- У каждого решения обычно есть цена; чистые бонусы оставляйте для редких наград.
- Результат не обязан полностью объяснять аномалию; он должен показать цену решения и оставить тревожный след.
- Даже успешное сдерживание может травмировать персонал, разрушить часть города или создать новый бюрократический абсурд.
- Одинаковые ресурсы не должны всегда означать одинаковую моральную позицию.
- Сюжетный выбор лучше помнить флагом и возвращать через несколько карт.
- Не каждая сюжетная цепочка обязана идти подряд: можно установить флаг и дать следующей части обычный вес.
- Проверяйте, что обе ветки не убивают один и тот же ресурс при любом разумном состоянии игрока.

## Идентификаторы

Используйте английский `snake_case`: `glass_signal_02`, `war_field_hospital`. Идентификатор не показывается игроку, но используется ссылками из очереди. Он должен быть уникален и не меняться после публикации контента.
