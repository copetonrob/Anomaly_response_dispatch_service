# Аномальная диспетчерская

Вертикальная карточная игра о диспетчере аномальной службы. Движок работает в браузере без сервера, сборки и зависимостей.

## Быстрый запуск

Откройте `index.html` в браузере. Чтобы проверить синтаксис и ссылки контента, при наличии Node.js выполните:

```powershell
npm run check
```

Для воспроизводимого расчёта баланса и массовой симуляции прохождений:

```powershell
npm run balance -- --runs=50000
```

Для публикации достаточно поместить весь каталог игры в архив или загрузить его содержимое на любой статический хостинг. Точкой входа остаётся корневой `index.html`.

## Где что лежит

- `src/content/registry.js` — реестр категорий и подключаемых наборов карт.
- `src/content/events*.js` — обычные самостоятельные события.
- `src/content/events/resource-lessons.js` — контрастные обучающие события по трём базовым ресурсам.
- `src/content/distortions.js` — «Искажения» с отдельным прогнозом и неожиданным фактическим исходом.
- `src/content/chains/` — короткие связанные цепочки об отдельных аномалиях.
- `src/content/stories/` — крупные ветвящиеся сюжеты, которые могут закончить игру.
- `src/content.js` — сборка всех наборов в общий пул, ресурсы, поражения и стартовые настройки.
- `src/game.js` — игровой цикл, условия, эффекты, селектор карт, сохранение и интерфейс.
- `styles.css` — мобильный интерфейс и свайпы.
- `ARCHITECTURE.md` — решения по устройству игры и алгоритм выдачи карт.
- `CONTENT_GUIDE.md` — справочник автора контента с шаблонами.
- `BALANCE.md` — постоянные метрики, методика симуляции и последний базовый результат.
- `scripts/analyze-balance.mjs` — воспроизводимый анализатор баланса и симулятор прохождений.
- `scripts/validate-content.mjs` — проверка ID, ссылок и структуры контента.
- `assets/icons` — атлас и четыре отдельные иконки ресурсов.
- `assets/cards` — иллюстрации отдельных карточек в компактном WebP.

Контент намеренно отделён от механики. Новые карты добавляются в соответствующий файл категории и автоматически попадают в общий пул после регистрации.
