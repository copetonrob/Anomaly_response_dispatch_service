# Аномальная диспетчерская

Вертикальная карточная игра о диспетчере аномальной службы. Движок работает в браузере без сервера, сборки и зависимостей.

## Быстрый запуск

Откройте `index.html` в браузере. Чтобы проверить синтаксис и ссылки контента, при наличии Node.js выполните:

```powershell
npm run check
```

Для публикации достаточно поместить весь каталог игры в архив или загрузить его содержимое на любой статический хостинг. Точкой входа остаётся корневой `index.html`.

## Где что лежит

- `src/content.js` — ресурсы, карты, поражения, концовки и стартовые настройки.
- `src/game.js` — игровой цикл, условия, эффекты, селектор карт, сохранение и интерфейс.
- `styles.css` — мобильный интерфейс и свайпы.
- `ARCHITECTURE.md` — решения по устройству игры и алгоритм выдачи карт.
- `CONTENT_GUIDE.md` — справочник автора контента с шаблонами.
- `scripts/validate-content.mjs` — проверка ID, ссылок и структуры контента.
- `assets/icons` — атлас и четыре отдельные иконки ресурсов.
- `assets/cards` — иллюстрации отдельных карточек в компактном WebP.

Контент намеренно отделён от механики. В обычной работе достаточно редактировать `src/content.js`.
