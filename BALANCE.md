# Баланс игры

Этот файл фиксирует постоянную методику оценки. После изменений контента выполните:

```powershell
npm run balance -- --runs=50000
```

Для машинно-читаемого полного отчёта добавьте `--json`. Симулятор использует фиксированный seed, поэтому одинаковая версия контента даёт воспроизводимый результат.

## Пространство безопасности

Все четыре шкалы переводятся в направление «больше — безопаснее»:

- `Hpersonnel = personnel`;
- `Hbudget = budget`;
- `Hsecrecy = secrecy`;
- `Hanomaly = 1 - anomaly`.

Это позволяет складывать разные ресурсы, не забывая, что аномальность имеет обратный смысл.

## Метрики

### Чистый дрейф

`D = Δpersonnel + Δbudget + Δsecrecy - Δanomaly`.

Положительный `D` означает общий выигрыш запаса безопасности, отрицательный — истощение. Метрика не заменяет анализ отдельных шкал: `+0.10` бюджета не спасает при нулевом персонале.

### Устойчивость состояния

Для выбора между вариантами симулятор использует:

`S = 0.5 × geometricMean(H) + 0.4 × min(H) + 0.1 × mean(H)`.

Минимальный запас имеет большой вес, поэтому стратегия старается спасать ближайшую к катастрофе шкалу. Геометрическое среднее штрафует сильный перекос между ресурсами.

### Коэффициент восстановления

Сумма всех положительных изменений запаса делится на абсолютную сумму отрицательных. Значение `1.00` означает, что восстановление компенсирует ущерб; ниже единицы — прохождение в среднем истощает игрока.

### Критический ход

Ход считается критическим, если хотя бы один запас безопасности не превышает `0.20`. Доля таких ходов показывает не только число поражений, но и продолжительность нахождения на грани.

### Политики игрока

- `random` — каждый выбор случаен; нижняя граница осмысленной игры.
- `novice` — в 65% случаев выбирает более устойчивый вариант по ожидаемым последствиям.
- `competent` — делает такой выбор в 80% случаев.
- `forecast` — всегда правильно оценивает обычные карты, но верит ложным прогнозам Искажений.
- `learned` — знает фактические последствия всех карт, включая Искажения.

Проценты `novice` и `competent` — модель точности решений, а не утверждение о поведении реальных игроков. После появления тестеров их следует откалибровать по телеметрии.

## Базовый результат — контент v4

Дата расчёта: 12 августа 2026 года. Каталог: 56 карт. Выполнено по 50 000 партий каждой политики, seed `20260812`.

### Статическая структура выбора

- Средний случайный вариант: **−1.10 процентного пункта** суммарного запаса.
- Средний лучший фактический вариант карты: **+3.30 п.п.**
- Средний худший вариант карты: **−5.50 п.п.**
- Положительные варианты: **46.4%**; нейтральные: **4.5%**; отрицательные: **49.1%**.

Среднее изменение одного случайного варианта по шкалам:

| Запас безопасности | Изменение |
|---|---:|
| Персонал | −1.05 п.п. |
| Бюджет | −0.94 п.п. |
| Секретность | +0.17 п.п. |
| Безопасность от аномальности | +0.72 п.п. |

Контент расходует прежде всего людей и деньги. Секретность почти нейтральна, а аномальность в среднем даже уменьшается.

По категориям средний вариант даёт:

| Категория | Чистый дрейф |
|---|---:|
| События | −0.79 п.п. |
| Искажения | −1.33 п.п. |
| Цепочки | −0.38 п.п. |
| Сюжеты | −3.29 п.п. |

Сюжетные решения закономерно самые дорогие. У всех шести вариантов Искажений знак фактического суммарного исхода противоположен знаку прогноза.

### Симуляции прохождений

| Политика | Победа | Средняя длина | Дрейф за ход | Восстановление/ущерб | Критические ходы |
|---|---:|---:|---:|---:|---:|
| Случайная | 16.8% | 32.81 | −1.62 п.п. | 0.85 | 23.8% |
| Новичок, 65% верных решений | 62.4% | 43.26 | −1.12 п.п. | 0.89 | 14.2% |
| Освоившийся, 80% | 95.4% | 47.72 | −0.20 п.п. | 0.98 | 3.9% |
| Идеально читает прогноз | >99.99% | 48.35 | +0.12 п.п. | 1.01 | 0.1% |
| Знает реальные исходы | >99.99% | 47.50 | +1.21 п.п. | 1.14 | <0.1% |

Погрешность вероятностей при 50 000 партиях составляет примерно 0.2–0.4 процентного пункта для трёх первых политик.

### Причины случайных поражений

Из 41 600 поражений случайной политики:

- бюджет — **56.2%**;
- персонал — **37.0%**;
- секретность — **6.3%**;
- аномальность — **0.5%**.

Все восемь авторских концовок финального сюжета встретились в симуляциях. Следовательно, победа и каждая финальная ветвь достижимы при текущих правилах.

## Вывод по текущей версии

Игра **в среднем идёт в минус**, если решения не оптимизировать. Однако понимание системы очень резко меняет результат: при 80% удачных решений вероятность победы уже около 95%. Главный источник поражений — бюджет, затем персонал; аномальность почти не создаёт угрозы.

Текущий баланс подходит для демонстрации обучения и запоминания, но для полной игры слишком щедр к освоившемуся игроку. При следующей балансировке разумная цель — сохранить случайную победу около 10–20%, но опустить результат `competent` примерно до 60–80%. Для этого полезнее усиливать ситуационное давление на высокий ресурс и аномальность, чем просто увеличивать все штрафы.
